Datum: 2026-05-05

Scope: Abgleich von `docs/lastenheft.md`, `docs/api.md`, `docs/data-model.md`,
`docs/permissions.md`, `docs/rtc.md`, `docs/deployment.md`, `docs/testing.md` gegen den aktuellen
Code-Stand. Der `v0.1.0-rc1` Scope ist ein API-/Backend-RC ohne voll nutzbare Produkt-UI.

Statuswerte:

- `implemented`: im aktuellen Code funktionsfaehig umgesetzt und durch Tests oder direkte
  Artefakte belegbar.
- `partially implemented`: technische Grundlage existiert, aber Bedienfluss, Produktionsreife,
  Testtiefe oder Teilanforderungen fehlen.
- `missing`: im aktuellen Code nicht umgesetzt.
- `not applicable`: bewusst nicht Teil des MVP oder fuer v0.1.0 nicht relevant.
